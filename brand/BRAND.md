## 名乗り方のルール（★法的に重要★）

法人登記をしていないので、**次の表記は使ってはいけません**（会社法 第7条・第8条違反）。

| ❌ 使ってはいけない | ✅ 使ってよい |
|---|---|
| ミセバ株式会社 | ミセバ |
| 株式会社ミセバ | ミセバ（屋号） |
| 合同会社ミセバ | Miseba |
| ミセバ社 | ミセバ / 担当：〇〇 |
| 会社ミセバ代表の〇〇 | ミセバの〇〇 |
| ミセバ代表 | ミセバ / 担当：〇〇 |

営業メッセージでの名乗り方の推奨形：

> ミセバの〇〇と申します。

「弊社」ではなく「こちら」「当方」を使う。組織の規模を偽らない。
**個人でやっていることを隠さない。** 月額の継続契約を売る商売なので、
後から「一人だったのか」と分かって信頼を失う方が損失が大きい。

登記は不要（任意）。変更したくなったら、翌年の確定申告書の屋号欄に新しい名前を書けば済みます。

## トーン＆マナー

営業メッセージ・サイト文言の共通トーン。

- **控えめで丁寧**。押し売りにしない
- 効果を断定しない（「必ず集客できます」は禁止）
- 専門用語を使わない（LP / SEO / CVR / レスポンシブ → 全部言い換える）
- 一方的に送っていることへの配慮を必ず入れる
- 相手は職人・個人事業主。忙しい。**結論を先に、短く**

## 価格（確定）

| 項目 | 金額 |
|---|---|
| 初期制作費 | **50,000円**（税込・**修正2回まで**） |
| 月額 | **5,000円** |
| 最初の3件のみ | **30,000円**（条件：**実績として紹介させてもらうこと**） |
| 慣れてから | 初期 8〜15万円 ／ 月額 5,000〜10,000円 |

相場（2026年）はフリーランスで初期10〜50万円・月1〜3万円。
5万円は**相場の下限**です。これ以上安くすると「なぜ安いのか」と警戒されます。

**値引きは必ず交換条件とセットにする。** 理由なく安くすると、
安さが理由の客しか来ず、修正無制限になって時給が崩壊します。

月額の中身は「サーバー保守」ではなく、**人がやる作業**として売る。

- 月1回の内容更新
- Googleマップの口コミへの返信代行
- 季節のお知らせ差し替え
- 電話でのご相談

理由：技術的な保守はAIが最も早く代替する領域。人的な対応は代替されにくい。
