このファイルは **Claude Code が毎回読む法務のルールブック**です。
`CLAUDE.md` がデザインと制作のルールなら、こちらは**やってよいこと／いけないこと**のルール。

> ⚠️ これは法律の専門家による助言ではありません。実際に問題が起きたとき、
> または売上が立って規模が大きくなったときは、弁護士・税理士に相談してください。

1. **メールで一斉に営業してはいけない**（特定電子メール法）

## 1. 連絡手段ごとの可否

| 手段 | 可否 | 根拠と条件 |
|---|---|---|
| **郵便（はがき・封書）** | ⭕ **推奨** | 送信規制なし。受け取り拒否の意思表示があれば以後送らない |
| **電話** | 🔺 条件付き | 事業者向けの営業は特商法の電話勧誘販売規制の**適用除外**が原則。ただし**その場で契約しない**こと（下記 §3） |
| **メール** | ❌ **原則禁止** | 特定電子メール法のオプトイン規制。例外は「**ウェブサイトで公表している**団体・営業を営む個人のアドレス」だけ。**ミセバの相手はサイトが無いので、この例外に入らない** |
| **Googleマップのメッセージ** | ❌ **使えない** | Googleビジネスプロフィールのチャット機能は **2024年7月31日に提供終了**。機能自体が存在しない |
| **店舗への直接訪問** | 🔺 条件付き | 事業者向けなら訪問販売規制の適用除外が原則。ただし**その場で契約しない**こと |
| **SNSのDM** | ❌ 避ける | 各サービスの利用規約でスパム行為として禁止されていることが多い。アカウント停止のリスク |
| **LINE公式アカウント** | ⭕ **返信の受け皿として使う** | 特定電子メール法の**対象外**。ただし「こちらから送る」手段ではなく、相手から来てもらう入口として使う |

### メールについての補足（重要）

特定電子メール法の「オプトイン規制」には例外があり、
**ウェブサイトで自分のメールアドレスを公表している団体・営業を営む個人**には
同意なしで広告メールを送ってよいことになっています。

ただし条件が2つあります。

1. アドレスと併せて「**送信を拒否する旨**」の表示があれば、**例外にならない**
2. そもそも「ウェブサイトで公表している」ことが前提

**ミセバが狙うのは「ウェブサイトを持っていない店」です。**
つまり、この例外が使える相手が最初から居ません。**メールは使わない。**

例外的にメールを送ってよいのは、次の場合だけ。

- 相手から先に連絡が来た（問い合わせ・返信）
- 名刺を直接もらった
- 相手が明示的に「メールで送って」と言った

### 送るときに必ず入れる表示（郵便・メール共通）

- 屋号（ミセバ）と担当者名
- 連絡先（**LINE公式アカウント** `https://lin.ee/VGyzGYv` ／ メールアドレス）
- **今後不要な場合の連絡方法**（「不要でしたらご一報ください。二度とお送りしません」）

## 2. 試作サイトを勝手に作って公開することについて

これがミセバの手法の核心であり、**最も注意が要る部分**です。

### 何が問題になりうるか

| 法律 | どういうときに問題になるか |
|---|---|
| **不正競争防止法 2条1項1号** | その試作サイトが「**その店の公式サイト**」だと第三者に誤認されるとき（周知表示混同惹起） |
| **商標法** | 店名が登録商標で、同一・類似の役務について「商標としての使用」にあたるとき |
| **著作権法** | 相手のロゴ・写真・文章を使ったとき |
| **景品表示法** | 事実でない優良な表示（実績・資格・No.1）を書いたとき。**その広告の責任は店側にも及ぶ** |
| **信用毀損** | 事実と違う内容で、その店の評判を下げたとき |

### 必ず守る対策（1つでも欠けたら公開しない）

- [ ] `<meta name="robots" content="noindex, nofollow">` を入れる
- [ ] `docs/robots.txt` に `Disallow: /p/` がある
- [ ] URLはランダム文字列にする（推測できない）
- [ ] **どこからもリンクを張らない**（一覧ページを作らない）
- [ ] フッターに「ミセバが作成した試作サイトです」と明記する
- [ ] **本人以外に送らない・見せない**
- [ ] 相手のロゴ・看板写真・施工写真を使わない（画像はUnsplashのみ）
- [ ] 創業年・実績・資格・料金など、渡されていない事実を書かない
- [ ] 「不要ならご連絡ください。すぐに削除します」と伝える
- [ ] **削除を求められたら、その日のうちに消す**

`scripts/publish.py` がこのうち機械的に検査できる項目を自動チェックし、
1つでも欠けていたら公開を中止します。

### 対象にしてはいけない店（必ず除外する）

| 除外する店 | 理由 |
|---|---|
| 店名に「株式会社」「有限会社」「合同会社」が付く | 商標登録済みの可能性が高い。法務担当がいる可能性も |
| 全国チェーン・フランチャイズの加盟店 | 本部の商標・ブランド規定に抵触する |
| 士業（弁護士・税理士・司法書士・行政書士） | 各士業法に広告規制がある |
| 医療機関（病院・クリニック・歯科） | **医療広告ガイドライン**が別途あり、規制が厳しい |
| 薬局・鍼灸院・接骨院 | あはき法・柔整法の広告規制がある |
| 飲食店で食品衛生の表示が必要なもの | 表示ミスの責任が重い |

> ⚠️ `config.json` の初期キーワードに「整体・治療院」が入っていましたが、
> **接骨院・鍼灸院・整骨院は広告規制の対象**です。「リラクゼーション」「もみほぐし」など
> 医業類似行為に当たらない店だけにするか、業種ごと外してください。

## 3. 契約・お金について

### その場で契約しない

電話でも訪問でも、**その場で「じゃあお願いします」を取らない**。

理由は2つ。

1. 事業者向け取引は特定商取引法の適用除外が原則ですが、消費者庁は
   「営業のためかどうかは、**その人が取引に習熟しているかを総合的に判断**する」
   としています。一人親方や小規模店は、実質的に消費者と変わらないと判断されうる。
2. その場の勢いで取った契約は、後で必ずもめる。

**正しい流れ：** 試作を見てもらう → 検討してもらう → 相手から連絡が来る → 見積を出す → 書面で合意

### 見積・契約書に必ず書くこと

- 制作費（税込）と支払時期
- **修正回数の上限**（2回まで、など）
- 月額の内容と**解約方法**（「1ヶ月前の連絡で解約可」など）
- **著作権の扱い**（納品後の権利がどちらにあるか）
- 公開後のドメイン・サーバーの契約名義

### 開業届

事業を始めたら **1ヶ月以内に税務署へ開業届**を出します。無料。
**屋号「ミセバ」はこの開業届の「屋号」欄に書くだけで登録されます**（審査も費用も不要）。

出すメリット：

- 屋号名義の銀行口座が作れる（「ミセバ　〇〇」）
- 青色申告ができる（控除が大きい）
- 相手に「事業としてやっている」と説明できる

### 消費税・インボイス

- 売上1,000万円以下なら**免税事業者**。当面は消費税を納める必要はない
- ただし相手が課税事業者だと、**インボイス登録番号が無いと相手が控除できない**
- 5万円の取引なら影響は小さい。**当面は登録しなくてよい**が、聞かれたら
  「現在は免税事業者のため登録番号はありません」と正直に答える

## 4. 見込み客リストの扱い（個人情報保護法）

**個人事業主の氏名・電話番号・住所は個人情報です。**
「5,000件以上」という要件は**2017年に撤廃**されているので、**1件でも個人情報取扱事業者**になります。

### 守ること

| 義務 | ミセバでの実装 |
|---|---|
| 利用目的を決める | 「ホームページ制作の提案のため」。それ以外に使わない |
| 適正に取得する | Googleマップ等の**公開情報**のみ。名簿を買わない |
| 安全に管理する | `prospects/` は `.gitignore` 済み。**絶対にGitHubに上げない** |
| 第三者に渡さない | リストを他人に売らない・見せない |
| 消してと言われたら消す | `do_not_contact` にして、データも削除する |

### 絶対にやらないこと

- 名簿業者からリストを買う
- 集めたリストを他人に渡す・売る
- `prospects/` を公開リポジトリに push する

## 5. ミセバ自身のサイトについて（特定商取引法）

サイトに価格を載せて申込みを受けると、**通信販売**にあたる可能性があります。
通信販売には氏名・住所・電話番号などの表示義務があります。

ただし、特定商取引法は「**営業のために若しくは営業として締結するもの**」を
適用除外としています。ミセバの相手は事業者なので、原則としてこの除外に入ります。

**そのため、サイトに次の一文を必ず入れます。**

> 本サービスは事業者さま向けのサービスです。

そのうえで、信用のために次を載せます。

- 屋号（ミセバ）
- 運営者名
- 連絡先メールアドレス
- **「所在地・電話番号はご請求により遅滞なくお知らせします」**

自宅住所を公開したくない気持ちは当然なので、この形にします。
ただし**請求されたら実際に開示する**こと。開示しないなら書いてはいけません。

## 6. 屋号「ミセバ」について

### 使ってよい表記

| 場面 | 表記 |
|---|---|
| 名乗り | **ミセバの〇〇と申します** |
| サイト・はがき | **ミセバ**（個人事業） |
| 契約書・請求書 | **ミセバ　〇〇 〇〇**（本名を併記。屋号だけでは契約主体にならない） |
| 銀行口座 | **ミセバ　〇〇**（開業届の控えが必要） |

### 使ってはいけない表記

| ❌ 禁止 | 理由 |
|---|---|
| 株式会社ミセバ / ミセバ株式会社 | **会社法違反**。法人でないのに法人を名乗るのは禁止 |
| 合同会社ミセバ / ミセバ合同会社 | 同上 |
| ミセバ社 / 弊社 / 当社 | 法人と誤認させる |
| ミセバ代表 / 代表の〇〇 | 「代表」は法人の代表者を指す語。個人事業では不適切 |
| ミセバ銀行 / ミセバ保険 など | 規制業種名は使えない |

### やっておくこと

- [ ] **J-PlatPat**（https://www.j-platpat.inpit.go.jp/）で「ミセバ」を商標検索する（無料）
- [ ] 同じ名前で同種のサービスをやっている先行者がいないか、ウェブ検索で確認する
- [ ] 開業届の「屋号」欄に「ミセバ」と書いて提出する

## 7. 迷ったときの判断基準

**「これ、相手の立場だったら怒るか？」**

法律の条文より、まずこれで判断してください。
怒られそうなことは、たいてい法律のどこかに引っかかります。

そして、

**「その場で判断がつかないなら、送らない。」**

1件送らなくても失うものはありませんが、1件間違えると屋号ごと信用を失います。
