# 営業メッセージのテンプレート

`brand/BRAND.md` のトーンに従うこと。**200字程度**。長くしない。

---

## 基本形（電話・メッセージ共通）

```
{{店名}} ご担当者様

はじめてご連絡いたします。ミセバの{{担当者名}}と申します。

Googleマップで{{店名}}様を拝見し、ホームページをお持ちでないようでしたので、
勝手ながら試作のページを一枚作ってみました。

{{URL}}

AIを使って公開情報から作ったものなので、内容の追加や修正ができます。
お作りする場合は初期{{初期費用}}円、公開の維持と月1回の更新で
月{{月額}}円ほどで承っております。

突然のご連絡で恐れ入ります。ご不要でしたら、そのまま破棄していただいて構いません。
```

---

## 電話で話す場合の導入

```
突然のお電話で失礼いたします。ミセバの{{担当者名}}と申します。
今、少しだけよろしいでしょうか。

{{店名}}様のホームページを勝手に一枚作ってみまして、
もしよろしければ見ていただけないかというご連絡でした。
```

断られたらすぐ引く。食い下がらない。

---

## 書いてはいけないこと

| ❌ | 理由 |
|---|---|
| 「必ず問い合わせが増えます」 | 効果の断定。景表法上も危ない |
| 「ホームページが無いと損をしています」 | 相手の否定から入っている |
| 「今週中なら無料です」 | 期限を切った煽り |
| 「株式会社ミセバ」「弊社」 | 法人ではない（会社法違反） |
| 「レスポンシブ対応のLPを…」 | 専門用語。相手に伝わらない |
| 長文（400字超） | 読まれない |
