# find-prospects — 見込み客を登録する

## 最初に読む

**必ず `brand/LEGAL.md` §2（対象にしてはいけない店）と §4（個人情報）を読むこと。**

---

## 誰が何をやるか（★重要★）

**Googleマップの画面を見るのは、あなた（Claude）ではなくユーザーです。**

理由：Googleマップの検索結果はJavaScriptで描画されるため、
ウェブ取得ツールでは中身が読めません（実測済み・0件しか返らない）。
Places API は有料なので使いません（ミセバは無課金運用）。

| 工程 | 担当 |
|---|---|
| Googleマップで店を見て、HPが無い店を選ぶ | **ユーザー**（スマホで3秒／店） |
| 貼られた情報を選別・整形して登録する | **Claude** |
| 別名やSNSでサイトを持っていないか裏取り | **Claude**（ウェブ検索） |
| 除外業種の判定 | **Claude** |

---

## 手順

### 1. ユーザーに探し方を伝える

まだ情報が貼られていなければ、こう案内する。

> スマホでGoogleマップを開いて、「〇〇（業種）＋ お住まいの市区町村」で検索してください。
> 店をタップして、**「ウェブサイト」ボタンが無い店**だけを選びます。
> 店名・住所・電話番号・評価・口コミ件数・営業時間 をコピーして貼ってください。
> 口コミも2〜3件あると、サイトの文章が良くなります。

**1回あたり最大10件。** それ以上は受け取らない。

### 2. 除外する（★必ずやる★）

貼られた店のうち、次に当てはまるものは**登録しない**。

| 除外条件 | 判定のしかた |
|---|---|
| 店名に「株式会社」「有限会社」「合同会社」 | 店名を見れば分かる |
| 全国チェーン・FC加盟店 | 店名にブランド名＋地名が付いていたら疑う。ウェブ検索で確認 |
| 士業（弁護士・税理士・司法書士・行政書士） | 業種で判定 |
| 医療機関（病院・クリニック・歯科・医院） | 業種で判定 |
| 接骨院・整骨院・鍼灸院・薬局 | 業種で判定。「整体」も原則除外 |
| 既にサイトを持っている | **ウェブ検索で裏取りする**（下記） |

除外した店は登録せず、**理由を添えてユーザーに報告する**。

### 3. サイトの有無を裏取りする（Claudeの仕事）

Googleマップに「ウェブサイト」が無くても、実際には持っている場合がある。
各店について次を検索して確認する。

```
"<店名>" <市区町村>
"<店名>" ホームページ
```

見つかったら**除外**（`status: "has_website"`）。
Instagram / Facebook ページだけの場合は**対象に含めてよい**
（ただし営業文でその点に触れない）。

### 4. フォルダを作る

```
prospects/<slug>/info.json
```

`slug` は店名をローマ字化してハイフン区切り（例：`yamada-roofing`）。
既に同じ `slug` があれば**スキップ**（重複アプローチ防止）。

```json
{
  "slug": "yamada-roofing",
  "name": "山田屋根工事",
  "industry": "roofing",
  "area": "東京都〇〇区",
  "address": "東京都〇〇区1-2-3",
  "phone": "03-1234-5678",
  "rating": 4.6,
  "review_count": 8,
  "hours": ["月〜金 8:00〜18:00", "日 定休"],
  "review_highlights": ["雨漏りをすぐ直してくれました"],
  "maps_url": "https://maps.google.com/...",
  "found_at": "2026-08-18",
  "status": "found"
}
```

`industry` は `CLAUDE.md` §2-1 の表のキー
（`roofing` / `plumbing` / `construction` / `electrical` / `restaurant`）から選ぶ。

### 5. 報告する

- 登録した件数と店名
- **除外した店と、その理由**（これを必ず伝える。ユーザーの学習になる）

---

## やってはいけないこと

- **推測で埋める。** 曖昧な情報は空にするか、その店を外す。
  ここで推測した情報が、そのまま試作サイトに載って事故になる。
- 名簿業者からリストを買う（`brand/LEGAL.md` §4）
- `prospects/` を push する（`.gitignore` 済み）
- 大量・高速な収集。**1回10件まで。**
- 除外条件のチェックを飛ばす
