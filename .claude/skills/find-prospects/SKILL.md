# find-prospects — 見込み客を探す

## 方針

**Places API（有料）は使わない。** ミセバは無課金運用が前提。
代わりに**ブラウザツールでGoogleマップを普通に閲覧**して情報を読み取る。

これは人間が手で探すのと同じ操作を代行しているだけなので、
大量・高速なスクレイピングにはしないこと。**1回の実行で最大10件まで。**
機械的に何百件も収集しようとしない（Googleの利用規約上も、実務上も避けるべき）。

---

## 手順

### 1. 検索する

ブラウザツールで Googleマップを開き、対象エリア × 業種で検索する。

```
https://www.google.com/maps/search/<業種>+<エリア>
```

デフォルトの業種リスト（`config.json` の `keywords` で上書き可）：
- 屋根修理 / 水道業者 / 工務店 / 電気工事 / 外壁塗装

### 2. 条件で絞る

各店舗のパネルを開いて、次の条件を**全部**満たすものだけを候補にする。

| 条件 | 理由 |
|---|---|
| **ウェブサイトのリンクが無い** | これが最重要。あるなら対象外 |
| 評価 **4.0以上** | 低評価の店にサイトを作っても喜ばれない |
| レビュー **3〜30件** | 少なすぎ＝実態不明、多すぎ＝既に十分大きい |
| 電話番号がある | 連絡手段が必要 |
| 営業中（閉業していない） | |

### 3. 情報を読み取る

条件を満たした店について、パネルから次を読み取る。

- 店名 / 住所 / 電話番号 / 業種
- 評価 / レビュー件数
- 営業時間
- 口コミ 2〜3件（本文を短く。全文は取らない）
- GoogleマップのURL

### 4. フォルダを作る

```
prospects/<slug>/info.json
```

`slug` は店名をローマ字化してハイフン区切りにする（例：`yamada-roofing`）。
既に同じ `slug` のフォルダがあれば**スキップ**する（重複アプローチ防止）。

`info.json` の形式：

```json
{
  "slug": "yamada-roofing",
  "name": "山田屋根工事",
  "industry": "roofing",
  "address": "東京都〇〇区1-2-3",
  "phone": "03-1234-5678",
  "rating": 4.6,
  "review_count": 8,
  "hours": ["月〜金 8:00〜18:00", "日 定休"],
  "review_highlights": ["雨漏りをすぐ直してくれました"],
  "maps_url": "https://maps.google.com/...",
  "found_at": "2026-08-13",
  "status": "found"
}
```

`industry` は `CLAUDE.md` §2-1 の表のキー（`roofing` / `plumbing` /
`construction` / `electrical` / `clinic` / `restaurant`）から選ぶ。

### 5. 報告する

見つけた件数と店名の一覧を報告する。条件で落とした店があれば理由も簡潔に。

---

## 注意

- **1回の実行で最大10件。** それ以上は取らない。
- 読み取った情報が曖昧・不完全な場合は、**推測で埋めない**。
  そのフィールドを空にするか、その店を候補から外す。
  ここで推測した情報が、後の工程でそのまま試作サイトに載って事故になる。
- `prospects/` は `.gitignore` 済み。個人情報を含むので **絶対に push しない**。
- 既に `prospects/` にある店は再取得しない（`slug` で重複チェック）。
