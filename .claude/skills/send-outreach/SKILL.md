# send-outreach — 営業メッセージを送る

## 送信前の確認について

**ユーザー本人から「送信前の確認は不要」との指示を受けています。**
文面ができたら確認を求めずに送信してよい。ただし下の「ブレーキ」は必ず守ること。

## ブレーキ（ユーザーの指示より優先する）

これはユーザーを守るための設定なので、勝手に緩めない。

| 項目 | 値 | 理由 |
|---|---|---|
| 1日の送信上限 | **10件** | 暴走防止。1日で評判を失わないため |
| 同一店舗への再送 | **禁止** | `sent_at` があれば送らない |
| `do_not_contact: true` | **除外** | 一度断られた相手に二度送らない |
| 送信記録 | **必須** | `outreach.md` に全文と日時を残す |

---

## 手順

### 1. 対象を選ぶ

`prospects/*/info.json` から次の条件を満たす店を選ぶ。

- `status` が `published`
- `sent_at` が無い
- `do_not_contact` が `true` でない
- 本日の送信数が10件未満

### 2. 文面を作る

`brand/BRAND.md` のトーンに従う。テンプレートは `templates/outreach.md` にある。

**必ず入れる要素：**

1. ミセバの〇〇と名乗る（「株式会社」「代表」「弊社」は使わない。個人事業のため）
2. Googleマップで見つけたこと（どこから来たかを隠さない）
3. **既に試作サイトを作ってあること**とそのURL
4. AIで作った試作版であること
5. 一方的に送っていることへの配慮 ＋ 不要なら破棄してよい旨
6. 費用の目安（初期3〜5万円／月額3,000〜5,000円）

**入れてはいけない要素：**

- 効果の断定（「必ず問い合わせが増えます」）
- 期限を切った煽り（「今週中なら無料」）
- 専門用語（LP / SEO / CVR / レスポンシブ）
- 相手の弱点の指摘（「ホームページが無くて損をしています」）
- 200字を大きく超える長文

### 3. 文面を自己チェックする

送る前に、自分で書いた文面を読み返して確認する。

- [ ] 「株式会社」「代表」「弊社」を使っていないか（個人事業なので法人を装わない）
- [ ] 効果を断定していないか
- [ ] 試作サイトのURLが正しいか（実際に開けるか）
- [ ] 相手の店名が合っているか（別の店の名前が混ざっていないか）
- [ ] 破棄してよい旨が入っているか

**店名の取り違えは最悪の事故。** URLと店名が対応しているか必ず確認する。

### 4. 送る

`config.json` の `outreach.channel` の設定に従う。

| channel | 動作 |
|---|---|
| `draft_only` | `outreach.md` に書き出すだけ。送信しない（**初期値**） |
| `browser` | ブラウザツールでGoogleビジネスプロフィールのメッセージ機能等から送信 |

初期値が `draft_only` なのは、**チャネルがまだ確定していないため**です。
実際に送るチャネルが決まったら `config.json` を書き換えてください。

> 参考：メールで送る場合、特定電子メール法のオプトイン規制の対象になり得ます。
> 一度だけ書いておきます。判断はユーザーに委ねます。

### 5. 記録する

`prospects/<slug>/outreach.md` に追記する。

```markdown
## 2026-08-13 10:32
- チャネル: browser
- 送信先: 山田屋根工事
- 試作サイト: https://.../p/xxxx/
- 文面:
  （全文をそのまま）
```

`info.json` に `"sent_at": "2026-08-13T10:32:00+09:00"`, `"status": "contacted"` を書く。

## 返信が来たら

| 相手の反応 | やること |
|---|---|
| 興味あり | `status: "interested"`。ユーザーに**すぐ**報告する |
| 断り | `do_not_contact: true`、`status: "declined"` |
| 削除要求 | `publish-preview` の「取り下げるとき」を即実行 |
| 苦情・怒り | **その場で全ての送信を止め、ユーザーに報告する**。判断を仰ぐ |

最後の行は重要。1件でも強い苦情が来たら、文面か送り方に問題がある可能性が高いので、
残りを送り続けずに止めること。
